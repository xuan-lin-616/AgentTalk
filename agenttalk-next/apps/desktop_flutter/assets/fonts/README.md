# Source Han Sans SC（思源黑体）

内置中文字体，用于消除 Windows 上 Flutter 回退到宋体导致的锯齿/生硬。

- 文件：`SourceHanSansSC-Regular.otf`、`SourceHanSansSC-Medium.otf`
- 许可：SIL Open Font License 1.1（可免费商用、可随开源项目分发）
- 来源：Adobe Fonts，`source-han-sans` 2.005R 的 SC 子集 OTF
  （https://github.com/adobe-fonts/source-han-sans/releases/tag/2.005R）

已在 `pubspec.yaml` 中注册为 `SourceHanSansSC` family；`main.dart` 的
`ThemeData.fontFamily` 指向该 family。
